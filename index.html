À propos

JE SUIS Gouasmia Sifeddine, développeur web full-stack

Étudiant en Bachelor Développement web à HETIC (Paris), après une licence en informatique à l’USTHB, je suis capable de concevoir et développer une application web de A à Z : interface, API, base de données, tests et mise en production.

Côté front-end, je crée des interfaces responsives et accessibles en HTML, CSS, JavaScript, TypeScript et React. Côté back-end, je développe des API REST et des applications web avec Node.js et Express, Python avec Django et FastAPI, et j’ai de solides bases en programmation orientée objet avec Java. Je sais mettre en place l’authentification (JWT), la gestion des rôles et des permissions, la validation des données et les bonnes pratiques de sécurité. Je conçois et manipule des bases de données relationnelles (PostgreSQL, MySQL, SQLite, Oracle), en SQL ou avec un ORM comme Prisma.

Côté data et IA, j’ai des notions concrètes : nettoyage et préparation des données avec pandas, entraînement et évaluation de modèles de classification avec scikit-learn, puis mise à disposition du modèle via une API FastAPI et une interface Streamlit.

Au quotidien, je travaille avec Git et GitHub en équipe (branches, pull requests, revues de code), je conteneurise mes applications avec Docker et Docker Compose, j’écris des tests et j’automatise leur exécution avec GitHub Actions. En stage, j’ai livré une application de gestion du personnel déployée sur le réseau interne de l’entreprise et utilisée par ses équipes.

En parallèle, j’ai fondé Illusions, ma marque de streetwear, où je gère l’identité visuelle, le contenu et la communication digitale. Je suis à la recherche d’une alternance en développement web full-stack à partir de septembre 2027.

# Mon portfolio

**Auteur : Gouasmia Sifeddine**

## Description

Mon portfolio personnel, réalisé en **HTML, CSS et JavaScript**. Il présente mon parcours, mes services, mes projets et mes contacts.

## Sections

- **Home** : présentation avec texte animé (Typed.js).
- **About** : à propos de moi et CV.
- **Services** : ce que je propose.
- **Portfolio** : mes derniers projets.
- **Contact** : téléphone, email et réseaux sociaux.

## Fonctionnalités

- Menu latéral avec navigation entre les sections.
- Thème sombre avec sélecteur de couleur.
- Design responsive.

## Technologies

HTML5 · CSS3 · JavaScript · Font Awesome · Typed.js

## Lancer le projet

Ouvre le fichier `index.html` dans ton navigateur.
